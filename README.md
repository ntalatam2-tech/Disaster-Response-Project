# Disaster-Response-Project
Customer message and agent reply matching using TF-IDF and cosine similarity.
# Customer Response Prediction

## Project Description
This project matches customer messages with suitable agent replies.

## Dataset
The dataset contains 200 customer messages and 200 agent replies.

## Method Used
- Text preprocessing
- TF-IDF Vectorization
- Character-level n-grams
- Cosine Similarity
- Best-match prediction

## Dataset Split
- Training samples: 160
- Testing samples: 40

## Final Result
- Predictions generated: 40
- Average similarity: 30.02%

## Tools Used
- Python
- Pandas
- Scikit-learn
- Google Colab
